# 🚗 화성시남부노인복지관 이용자 차량등록 관리 시스템

화성시남부노인복지관 이용 어르신 및 방문객의 안전하고 원활한 부설주차장 이용과 비상 시 신속한 출차 연락을 지원하기 위한 **차량번호기록부 및 차량등록 서식 관리 시스템**입니다.

---

## 📌 주요 특징 및 목적

1. **어르신 맞춤형 인적사항 관리**
   - 어르신 본인 연락처 외에 긴급상황 및 대리 출차 요청을 위한 **보호자(가족) 비상연락처** 항목 필수 배치
2. **주차 구역 효율적 관리**
   - 일반차량, 장애인 전용주차 표지 부착 차량, 경차, 친환경(전기/하이브리드) 차량 구분 관리
3. **법적 요건 준수**
   - 개인정보보호법에 따른 수집 항목, 수집 목적, 보유 기간 명시 및 동의 확인 서식 내장
4. **온·오프라인 하이브리드 활용**
   - 전산 DB 관리용 엑셀 통합문서 및 현장 안내데스크 비치용 인쇄 서식(HTML) 동시 제공

## 📋 서식 세부 항목

### 1. 전산 관리대장 (Excel)
- **상단 통계 카드**: 총 등록 대수, 일반 차량, 장애인/배려 차량, 경차/친환경 차량 실시간 집계
- **입력 필드**:
  - `연번` / `등록일자` / `회원번호` / `성명` / `생년월일`
  - `연락처(휴대폰)` / `비상연락처(가족)`
  - `차량번호` / `차종 및 색상` / `차량구분` / `소유관계` / `주차증번호` / `비고`

### 2. 현장 비치용 수기 등록부
- 안내데스크 또는 주차관리실 클립보드 비치용
- 우측 상단 결재란 (담당 / 팀장 / 관장) 포함
- 서명란 및 하단 개인정보 수집·이용 안내문구 포함

### 3. 개별 차량등록 신청서
- 신규 등록 및 변경 시 이용자 제출 서식
- 인적사항, 차량 상세 정보, 차량 소유자 관계
- 복지관 주차장 이용 수칙 안내 및 개인정보 수집·이용 동의 체크란

## 🖨️ 인쇄 방법 안내

- **HTML 서식 사용 시**:
  - 파일을 더블 클릭하여 웹 브라우저(크롬, 엣지 등)로 엽니다.
  - 상단의 **[🖨️ 인쇄하기]** 버튼을 누르거나 `Ctrl + P`를 누르면 여백에 맞춰 깔끔하게 출력됩니다.
- **Excel 서식 사용 시**:
  - 엑셀 파일 열기 후 `시트 2` 또는 `시트 3`을 선택하고 `Ctrl + P`를 누르면 A4 용지 1장에 자동 맞춤 설정되어 인쇄됩니다.
